# Commit Message Guide
## Formula
<Action> <where/topic> <what>
## Common Actions
- Add = new file, folder, exercise, feature
- Update = improve existing file/content
- Fix = correct bug, typo, mistake
- Remove = delete something
- Rename = change name
- Refactor = improve code structure without changing behavior
- Organize = clean folder/project structure
## Examples
```bash
git commit -m "Add cpp06 loops exercise"
git commit -m "Update cpp05 vector notes"
git commit -m "Fix typo in README"
git commit -m "Remove unused test file"
git commit -m "Rename cpp02 functions folder"
git commit -m "Refactor log level helper functions"
git commit -m "Organize C++ exercise folders"
